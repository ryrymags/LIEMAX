# POV Reference Assets

This folder holds local reference imagery for the Three.js POV prototype.

- `spiderverse-143-reference.webp` is a user-supplied 1.43:1 test image used to
  verify projection placement and crop behavior in `docs/pov.js`.
- Keep reference media as standalone files, not base64 strings embedded in code.
- Replace or remove this asset before public redistribution if licensing is not
  cleared.
